# Raven Castle

**Discover Raven Castle and its restoration journey!**

**Raven Castle** is a website project introducing a newly discovered historic castle hidden in an ancient forest. The project aims to restore the castle to its original splendor and provide visitors with all relevant information about the site.

## Features

- **Castle Overview** – Learn the castle’s history and ongoing restoration.  
- **Programs & Activities** – Explore medieval-themed events, guided tours, and special programs.  
- **Opening Hours** – Check visiting times and seasonal schedules.  
- **Ticket Prices** – View prices, group discounts, and special offers.  
- **Contact** – Reach the team for inquiries or bookings.

## Tech Stack

- **Frontend:** React + Vite + TypeScript  
- **Styling:** Tailwind CSS  
- **Icons:** Lucide-Icons  
- **Multi-language support:** react-i18next

## Customize the Castle

The castle’s design is flexible — you can create a **mysterious, gothic** look or a **modern, futuristic** style.

# Hollóvár

**Fedezd fel Hollóvár történetét és helyreállítását!**

A **Hollóvár** weboldal célja, hogy bemutassa a nemrég felfedezett történelmi várat, amely egy ősi erdő mélyén található. A projekt célja a vár eredeti pompájának helyreállítása, és hogy a látogatók teljeskörű történelmi élményben részesüljenek.

## Funkciók

- **Várleírás** – Ismerd meg a vár történelmét és a felújítás részleteit.  
- **Programok és események** – Vegyél részt középkori témájú rendezvényeken, vezetett túrákon és különleges programokon.  
- **Nyitvatartás** – Tekintsd meg az aktuális látogatási időket és szezonális információkat.  
- **Jegyárak** – Nézd meg a belépődíjakat, csoportos kedvezményeket és akciókat.  
- **Kapcsolat** – Lépj kapcsolatba a csapattal kérdések vagy foglalás esetén.

## Technológiák

- **Frontend:** React + Vite + TypeScript  
- **Stílus:** Tailwind CSS  
- **Ikonok:** Lucide-Icons  
- **Többnyelvű támogatás:** react-i18next

## Testreszabás

A vár megjelenése szabadon alakítható: legyen **gótikus és misztikus**, vagy **modern, futurisztikus**.
